# Research Methodology #

## Overview

This research adopts a data-driven methodology based on the Cross-Industry Standard Process for Data Mining (CRISP-DM). The methodology is suitable because the study focuses on comparing existing privacy-preserving techniques instead of developing a new software system.

The comparison is performed using the UCI Adult Census Income dataset. Three techniques are evaluated, namely data anonymization, differential privacy, and federated learning. Each technique is applied to the same dataset to ensure a fair comparison.

The evaluation focuses on several criteria, including data utility, privacy protection, re-identification risk, computational overhead, and scalability. The findings are used to develop a comparative framework that can assist researchers and practitioners when selecting an appropriate privacy-preserving technique for big data applications.

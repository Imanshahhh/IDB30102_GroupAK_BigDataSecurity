# Expected Outcome

- This research is expected to show the differences between k-Anonymity and Differential Privacy.

- Both techniques will be tested using the same UCI Adult Census Income dataset and the same evaluation criteria.

- The preliminary results already show different values for accuracy, uniqueness-based risk indicator, and execution time.

- The final results will be used to see which technique gives better results under the selected criteria and to understand the trade-off between privacy, data utility, and processing time.

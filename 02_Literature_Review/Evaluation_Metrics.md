# Evaluation Metrics #

The following metrics are used to compare the selected techniques.

| Metric | Description |
|---------|-------------|
| Classification Accuracy | Measures prediction performance |
| Re-identification Risk | Measures privacy protection |
| Privacy Budget (ε) | Measures privacy strength |
| Information Loss | Measures data utility |
| Processing Time | Measures execution performance |
| Communication Cost | Measures communication efficiency |
| Scalability | Measures performance on larger datasets |

# Comparison of Existing Techniques #

## Overview

The table below compares the main privacy-preserving techniques identified from previous studies.

| Technique | Advantages | Limitations |
|-----------|------------|-------------|
| Data Anonymization | Easy to implement and maintains data utility | Re-identification risk still exists |
| Differential Privacy | Strong privacy guarantee | Reduced model accuracy due to added noise |
| Federated Learning | Raw data remains on local devices | Communication overhead and gradient leakage |

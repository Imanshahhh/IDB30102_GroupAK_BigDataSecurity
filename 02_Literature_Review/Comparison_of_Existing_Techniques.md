# Comparison of Existing Techniques #

## Overview

This section compares the three main privacy-preserving techniques identified from the reviewed studies. Each technique has different strengths and limitations when protecting sensitive information in big data systems.

| Technique | Main Strength | Main Limitation |
|-----------|---------------|-----------------|
| Data Anonymization | Preserves data utility and is easy to implement | Re-identification is still possible |
| Differential Privacy | Provides strong mathematical privacy guarantees | Utility and model accuracy may decrease due to added noise |
| Federated Learning | Raw data remains on local devices | Communication overhead and gradient leakage |
